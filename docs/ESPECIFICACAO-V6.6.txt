# 4. AMBIENTE OPERACIONAL OFICIAL

## 4.1 Debian 13 + KDE Plasma

Utilizar Debian 13 Stable como sistema principal de desenvolvimento e operação local.

Executar preferencialmente de forma nativa:

- Command Center.
- Backend.
- Frontend.
- PostgreSQL.
- Detection Engine.
- Rust Toolchain.
- Python.
- Node.js.
- Git.
- SecureBuild.
- Agente Linux.
- Serviço de auditoria.
- Geração de relatórios.
- Gerenciamento de projetos.

Utilizar systemd quando apropriado.

Priorizar componentes modulares e inicialização sob demanda.

## 4.2 Podman rootless

Utilizar Podman opcionalmente para:

- Ferramentas leves.
- Ambientes descartáveis.
- Workers auxiliares.
- Testes de integração.
- Análise de dependências.
- Processos de auditoria de baixo risco.

Aplicar:

- Permissões mínimas.
- Limites de recursos.
- Imagens verificadas.
- Redes restritas.
- Montagens mínimas.
- Proteção de segredos.

Não considerar contêineres uma barreira equivalente a máquinas virtuais.

Podman não será dependência obrigatória do núcleo do Sentinel.

## 4.3 Kali Linux virtualizado

Utilizar QEMU/KVM, libvirt e virt-manager.

O Kali Linux será utilizado para:

- Laboratórios ofensivos autorizados.
- Pentests.
- Exercícios Purple Team.
- Simulações controladas.
- Testes com sistemas operacionais completos.
- Investigações que exijam kernel próprio.
- Laboratórios de redes isoladas.

A máquina virtual permanecerá desligada quando não estiver sendo utilizada.

Não executar atividades ofensivas fora de sistemas próprios ou explicitamente autorizados.

## 4.4 Windows

Desenvolver a plataforma para funcionar progressivamente também no Windows.

O frontend, backend e banco deverão utilizar tecnologias multiplataforma sempre que possível.

Funcionalidades que dependam do sistema operacional deverão possuir adaptadores próprios.

Planejar um agente Windows em Rust com integração a APIs oficiais de telemetria.

Não presumir paridade imediata entre Linux e Windows.

## 4.5 Hardware inicial

Considerar:

- Aproximadamente 16 GB de RAM.
- NVIDIA GeForce GTX 1050 com 4 GB de VRAM.
- SSD Kingston A400 de 480 GB comerciais.
- HD externo de 1 TB.
- Dual boot Windows/Debian.

O modelo do processador deverá ser verificado.

Planejar o consumo de RAM, CPU, disco e GPU antes de iniciar novos serviços.
